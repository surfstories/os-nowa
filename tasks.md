# Tasks

Open items only. One line each. When something is done it comes **off** this list — the record that
it happened goes in the log of whatever domain it belonged to.

That is the whole design. A task list that accumulates finished work stops being a list of what to
do and becomes an archive nobody reads. There are no priorities, no statuses and no categories here
on purpose: every one of those is a field that has to be maintained, and maintaining a task list is
itself a task.

Format — a dash, the thing to do, and a date only if there is a real deadline:

```markdown
- Send the signed lease back to the agency [by 2026-08-20]
- Work out whether the annual plan is cheaper than monthly
- Ask the accountant which receipts they still need
```

If an item has not moved in a month, that is information. Either it matters and it is blocked, or it
does not matter and it should be deleted. Both are fine; leaving it to sit is what is not.

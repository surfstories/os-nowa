# Priorities

What the user is actually working toward right now, ranked, with a date on the list. Three to five
items — a ranked list of twelve is not ranked.

This is the file that lets an agent tell important from urgent without asking. Re-read it with the
user every few weeks; a stale priority list is worse than none, because it is confidently wrong.
